# GEMINI.md

This project keeps its agent guide in **[CLAUDE.md](CLAUDE.md)** — one file, every agent.
Read it before making any change, along with **[docs/LEARNINGS.md](docs/LEARNINGS.md)**
(failure modes captured from real agent runs).

The name is historical, not vendor-specific: Gemini CLI loads `GEMINI.md`, OpenAI Codex
loads `AGENTS.md`, and Claude Code loads `CLAUDE.md`, so this file and `AGENTS.md` exist
only to point all three at the same source of truth.

> Fresh install? `CLAUDE.md` doesn't exist yet — copy `CLAUDE.template.md` to `CLAUDE.md`
> and fill in the placeholders.
